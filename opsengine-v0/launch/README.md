# OpsEngine launch kit

Everything needed to get OpsEngine its first paying customers. Claude prepares everything;
the founder does **one task a day, 15 minutes or less** (see `05_daily_tasks.md`).

| File | What it is |
| --- | --- |
| `01_one_page_pitch.md` | What we offer, to whom, why now, the pilot offer |
| `02_outreach_safety_consultants.md` | Messages to find the qualified safety partner |
| `03_outreach_subcontractors.md` | Messages + the 10 discovery conversations with subcontractors |
| `04_only_you_checklist.md` | The few things that legally need the founder, step by step |
| `05_daily_tasks.md` | The day-by-day plan. Tick a box when done |
| `06_build_sprint.md` | The pilot-ready build (logins, email, approve-by-link, hosting, GDPR) |
| `07_pilot_onboarding.md` | Checklist for loading the first real customer |
| `08_gdpr_pack.md` | Data protection drafts (privacy notice, processing terms, retention) |
| `09_pilot_agreement.md` | Pilot agreement draft for a solicitor to check |
| `10_onboarding_email.md` | The email asking a new pilot customer for their documents |
| `11_outreach_list.md` | 22 Dublin/Leinster subcontractors to contact, with message templates |
| `12_pricing.md` | Internal pricing plan to test on calls (not public yet) |
| `13_first_five_messages.md` | The first 5 firms checked, with personalised messages ready to paste |
| `pitch/ClearToWork_pitch.pdf` | One-page pitch PDF to attach to emails (source: `pitch/pitch.html`) |
| `../../cleartowork-explainer/` | 57 s explainer video (house character + voice) for outreach and the website |
| `../site/index.html` | The cleartowork.ie website (one page; served by Caddy, see `../deploy/`) |

Brand: customers see **ClearToWork** (portal, emails, reports, website); OpsEngine is the engine.

**How to use it:** start any session with *"OpsEngine, what's today's task?"*. Claude reads
`05_daily_tasks.md`, finds the first unticked task, prepares everything for it, and hands over
one small thing to do.

**Honesty rule for all outreach:** OpsEngine v0 runs on sample data and its outside-world
actions are simulated (see `../AUDIT.md`). So we sell a **pilot of a done-for-you service**,
run by us with the engine behind the scenes, not a finished self-serve app. Never claim the
software certifies compliance; qualified people sign off safety documents.
