# SOC Academy

My 6-month plan to become a SOC Analyst, then a cybersecurity engineer — with an AI teacher.

## How to use the teacher

Open a Claude Code session on this repo (phone, web or desktop) and type:

```
/soc-teacher
```

Then say what you want:
- **"teach me"** — next lesson on the roadmap
- **"quiz me"** — 10 scenario questions on what you've learned
- **"alert drill"** — investigate a realistic SOC alert
- **"mock interview"** — practise a SOC Analyst interview
- **"review"** — am I on track?

The teacher remembers you through [`PROGRESS.md`](PROGRESS.md) and saves your notes in [`notes/`](notes/).

- 📅 Plan: [`ROADMAP.md`](ROADMAP.md)
- 📈 Progress: [`PROGRESS.md`](PROGRESS.md)
