# THE AGENCY (Part 1)

An original, fictional storytime short (~93 s, 1080x1920). All names, places and events are invented.
Main character: the house girl character (red hoodie, black joggers, long dark hair); voice: house girl voice
(Kokoro `af_heart`, ~185 wpm, each line read in one continuous pass). Built on the toolkit in `../2am-delivery`.

    python tts.py      # voiceover + timeline.json
    python audio.py    # music box, drone, sfx, mix -> $SCR/agency_mix.wav
    python render.py --still 42 frame.png
